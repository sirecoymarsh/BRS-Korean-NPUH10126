# 검증 보고서

v1.0.1 2-3 긴급 수정의 현재 기준 보고서는 다음과 같습니다.

- `current_candidate_qa.json`: 커밋 후보 요약
- `release_build_report.json`: 원본/목표/델타/글꼴/ISO 검증 요약
- `bscr_fixed_slot_audit_actual_iso_build.json`: 88개 BSCR 독립 구조 감사
- `stage_2_3_runtime_confirmation.json`: 사용자 2-3 통과 확인
- `stage_3_2_portal_static_audit.json`: 3-2 정적 검사(런타임 보류)
- `powershell_patcher_test_report.json`: 배포 설치기 왕복 검증
- `ppsspp_final_qa_report.json`: PPSSPP 런타임 주장 범위
- `font_verification.json`: 글꼴/ucs2jis 허용 범위 검증

그 밖의 파일은 v1.0 번역·UI·컷씬 제작 이력 및 시각 증거입니다. 모든 공개 JSON은
게임 ISO 경로와 로컬 작업 경로를 제외하거나 치환한 상태입니다. ISO 자체는 저장소에 없습니다.
