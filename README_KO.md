# BLACK★ROCK SHOOTER THE GAME 한국어 패치 v1.0.1

대상은 미국 PSN판 `NPUH10126`입니다. 배포본에는 게임 ISO가 들어 있지 않으며,
사용자가 보유한 지원 원본으로 새 한국어판 ISO를 생성합니다. 원본 ISO는 수정하지 않습니다.

## 추가·변경 사항

이 절은 원판(미국 PSN판 `NPUH10126`)과 비교해 이 패치가 무엇을 더하고 바꿨는지를 커밋 기록·릴리스 노트·`REPORTS/` 보고서에서 모아 정리한 것입니다. 괄호 안은 근거(커밋 앞 7자, 릴리스 태그, 보고서 파일 이름)이며, 확실하지 않은 내용은 「(추정)」으로 표시했습니다.

### 관련 저장소: 4K 애셋 리마스터

[black-rock-shooter-4k-asset-remaster](https://github.com/sirecoymarsh/black-rock-shooter-4k-asset-remaster)는 이 한국어 패치와 **별도의 작업**입니다.

- 이 저장소(BRS-Korean-NPUH10126)는 **한국어 패치 본체**입니다. 원본 ISO에 차분을 적용해 한국어판 ISO를 만들고, 선택 설치로 UI 27장짜리 8배 HD UI 팩을 줍니다. v1.0.1까지 공개 배포됐습니다.
- 4K 애셋 리마스터 저장소는 이 한국어 패치판에서 실제로 불리는 텍스처를 바탕으로 캐릭터·적·배경·전투 HUD·효과까지 PPSSPP 고해상도 텍스처 팩을 만들려던 작업 공간입니다. 이 저장소의 HD UI 27장은 그쪽의 기준 자료로 쓰였습니다.
- 4K 리마스터는 사용자 요청으로 **일시정지(개발 체크포인트로 저장)**된 상태이고, 배포 팩은 아직 없습니다. 얼굴·의상 모델 이식 후보와 2026-09-24 정상 로딩 확인본도 그쪽에 보존돼 있습니다.

### 번역 범위

- **기준 원문**: 미국 PSN판의 영어 문장을 원문으로 번역했습니다(`REPORTS/governor_term_correction_report.json`의 원문 예시 기준).
- **번역한 것**: 대사, 컷씬 자막, 아이템명, 시스템 문구, 적 이름·부위·전투 메시지, 챌린지·미션 UI, 필드 지역 이름, 스테이지 선택, 이벤트 대화 등 **4,777항목**(v1.0 릴리스 노트, `REPORTS/language_release_gate_report.json`). 구성은 스테이지·공통 컷씬 대사(BSCR) 1,690항목, 아이템·시스템 UI 789항목, 적 이름·전투 메시지 278항목, 미션·챌린지 표시 638항목, 이벤트 대화 1,382항목 등입니다.
- **그래픽 UI 글자**: 메뉴·아이템·옵션·전투·필드 시스템 UI의 그림 글자 라벨 100개를 27개 그림 파일(PTMD)에 한글로 다시 그려 ISO 안에 직접 넣었습니다. 이 부분은 텍스처 팩 없이도 보입니다(6e62375, `REPORTS/CUTSCENE_AND_UI_FIX.md`).
- **이름 표기 원칙**: 인간·시스템 발신자 이름은 한국어로 바꿨습니다. 외계인 고유명 `Mii / Mazuma / Shizu / Karli / Lilio / Nafe / Zaha`는 원작의 라틴 표기를 그대로 두었고, 통신 발신 코드 `MEFE / MZMA / SZZU / CKRY / LLWO / XNFE / SAHA`도 라틴 표기를 유지합니다(b50574b, `REPORTS/alien_name_reversion_final_validation.json`).
- **용어 교정**: `General` 직함을 「장군」에서 문맥에 맞는 「총독」으로 31항목(9개 파일) 바꿨습니다(1a0a7f2, `REPORTS/governor_term_correction_report.json`).
- **영어로 남긴 곳**: 필드 `★MENU`의 `CUSTOMIZE / ITEMS / CHALLENGES / OPTIONS / EXP / NEXT / LEVEL` 라벨은 여러 고정 조각을 이어 붙이는 초소형 그림이라, 한글판을 시험해 보니 글자가 잘리고 섞여서 원문 영어를 유지했습니다(be497ab, `REPORTS/CUTSCENE_AND_UI_FIX.md`). 스테이지 선택 화면의 보조 영문 라벨과 아이콘도 원본 그대로입니다.

### 화면·그래픽 개선

- **한글 글꼴**: 게임 글꼴 파일(font.lpk)에 Noto Sans KR 기반 한글 919자를 넣고, 문자 변환표(ucs2jis)를 함께 고쳤습니다(`REPORTS/font_verification.json`, `LICENSES/NotoSansKR-OFL.txt`).
- **픽셀 한글**: 스테이지 선택 화면의 「저장·로드·메뉴」 등 작은 라벨은 Galmuri 픽셀 글꼴로 원본 줄 위치에 맞춰 그렸습니다(be497ab, `LICENSES/Galmuri-OFL.txt`).
- **선택 설치 PPSSPP HD UI 팩**(`BRS_Korean_HD_UI_Pack.zip`): UI 텍스처 27장을 8배 해상도로 바꿉니다. 스테이지 외계인 코드를 LLWO 기준으로 가운데 정렬했고, SAHA 뒤에 `I`처럼 보이던 잔여 픽셀을 지웠습니다. 이 팩은 표시 전용이고 ISO를 바꾸지 않습니다(1a0a7f2, b50574b, `REPORTS/hd_ui_pack_report.json`, `REPORTS/stage_saha_cleanup_qa.json`).
- 캐릭터·배경 같은 UI 밖의 고해상도 텍스처는 이 저장소에 없습니다. 그 작업은 위의 4K 애셋 리마스터 저장소에서 진행하다 멈췄습니다.

### 버그 수정

이 패치의 이전 판에서 생긴 문제를 고친 기록입니다(원판 버그 수정은 없습니다).

- **컷씬 자막 `@@@@`·누락**: 컷씬 대사(BSCR)를 Shift-JIS가 아니라 UTF-8 기반으로 다시 인코딩하고, 문자열 참조 37,139개를 모두 다시 연결했습니다. STG04 컷씬에서 한국어 자막 표시를 확인했습니다(6e62375).
- **메뉴 글자 갈라짐·잘림**: 그림 UI의 배치와 여백을 다시 잡고, 게임이 잘라 쓰는 영역(UV)을 실제로 재서 다시 그렸습니다(6e62375, be497ab).
- **2지역 3번째 미션(2-3) 진행 정지·크래시 (v1.0.1 긴급 수정)**: 번역 문자열을 옮기면서 뒤따르는 스크립트 코드 주소가 바뀐 것이 원인이었습니다. 컷씬 대사 88개 파일 모두에서 번역문을 원본 문자열 자리 안에 넣고 남는 자리는 공백으로 채워, 파일 크기·주소 변화를 0으로 만들었습니다. 사용자가 2-3 통과를 직접 확인했습니다(8e627de, v1.0.1, `REPORTS/bscr_fixed_slot_audit_actual_iso_build.json`).
- **체크섬 목록 정합성**: `CHECKSUMS.sha256`의 값 하나를 바로잡았습니다(0bdae1b).

### 설치·제거 방식

- **원본 확인**: 미국 PSN판 `NPUH10126`, 1,360,363,520바이트, SHA-256 `4735b0d0…a6d23f0e`가 모두 맞아야 적용합니다.
- **적용**: 자체 이진 차분 형식(`.brspatch`, zlib 압축 레코드 4,084개)을 `Apply-KoreanPatch.bat`(또는 `.ps1`)이 읽어, 원본은 그대로 두고 옆에 `_Korean_v1.0.1.iso`를 새로 만듭니다. 결과물 해시까지 확인하며, 원본을 덮어쓰는 출력 경로는 거부합니다.
- **제거**: `Restore-Original.bat`은 패치가 만든 ISO가 정확히 일치할 때만 그 파일을 지웁니다. 원본은 처음부터 바뀌지 않습니다.
- **HD UI 팩**: 압축 안 `PSP` 폴더를 PPSSPP 메모리스틱에 합치고 텍스처 교체를 켭니다. 지우면 원래대로 돌아갑니다.
- **지원 환경**: Windows PowerShell 5.1로 적용, PPSSPP v1.20.4에서 시험했습니다. PSP 실기는 시험 기록이 없습니다.

### 알려진 문제

- 3지역 2번째 미션(3-2)의 포탈 이동은 정적 검사만 통과했고, 실제 플레이 확인은 아직 보류입니다(`REPORTS/stage_3_2_portal_static_audit.json`).
- 일반 대화 속 외계인 이름의 한국어 표기 보강은 따로 준비했지만 실행 검증 전이라 v1.0.1에 넣지 않았습니다.
- 필드 `★MENU` 라벨은 영어로 남아 있습니다.
- 모든 스테이지를 처음부터 끝까지 다시 플레이한 검증 기록은 없습니다(v1.0.1은 2-3 회귀 확인 범위).
- v1.0 릴리스 노트는 4,777항목이라고 적었지만, v1.0.1의 `RELEASE_REPORT.json`에는 번역표 항목 수가 4,742로 적혀 있습니다. 두 번역표의 차이(35항목)가 무엇인지는 기록에 없습니다(추정: 중복 정리).

## v1.0.1 긴급 수정

- 2지역 3번째 미션에서 도입 컷씬 뒤 진행이 정지하거나 크래시하던 문제를 수정했습니다.
- 원인은 번역된 BSCR 문자열 재배치로 후속 바이트코드 주소가 달라진 것이었습니다.
- 모든 BSCR 번역을 원본 슬롯 안에 넣고, 남는 바이트는 원본 NUL 앞에서 공백으로 채웁니다.
- 사용자 실행 검증으로 **2-3 통과**를 확인한 정확한 ISO 해시를 배포 대상으로 사용합니다.
- 3지역 2번째 미션 포탈 관련 파일은 정적 구조 검사를 통과했지만, 런타임 확인은 아직 보류입니다.

## 설치

원본 ISO를 `Apply-KoreanPatch.bat` 위에 끌어다 놓거나, 이 폴더에서 다음을 실행합니다.

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File ".\Apply-KoreanPatch.ps1" -SourceIso "<원본_ISO_경로>"
```

출력 경로를 생략하면 원본과 같은 폴더에 `_Korean_v1.0.1.iso`가 생성됩니다.

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File ".\Apply-KoreanPatch.ps1" -SourceIso "<원본_ISO_경로>" -OutputIso "<출력_ISO_경로>"
```

완성본 검증값:

- 크기: `1,378,271,232`바이트
- SHA-256: `525b5d2b7d8f4723be25b026e72b69d07d30c2cf84d8a48235577ca3728fc92a`

## 패치 범위와 표기

- 대사, 컷씬 자막, 아이템명, 시스템 문구를 반영했습니다.
- `General` 직함은 문맥에 맞게 `총독`으로 통일했습니다.
- 통신 발신 코드 `MEFE / MZMA / SZZU / CKRY / LLWO / XNFE / SAHA`는 라틴 표기를 유지합니다.
- 이번 v1.0.1은 사용자가 2-3 통과를 확인한 정확한 긴급 수정본입니다. 일반 에일리언 이름의
  한국어 표기 보강은 별도 런타임 후보에서 검증 중이며 이 정확한 긴급 수정본에는 섞지 않았습니다.
- ★MENU의 고정 그래픽 메뉴 라벨은 영어를 유지합니다.

## 선택 설치: PPSSPP HD UI 팩

`BRS_Korean_HD_UI_Pack.zip`은 PPSSPP 전용 선택 설치 팩입니다. 압축 안의 `PSP` 폴더를
PPSSPP 메모리 스틱 루트에 합친 뒤 **Replace Textures(텍스처 교체)** 를 켜십시오.
이 팩은 표시 전용이며 ISO 자체를 바꾸지 않습니다.

## 복원
